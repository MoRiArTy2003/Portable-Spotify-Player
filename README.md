# Portable Spotify Player

A standalone Spotify companion built using the ESP32-S3.

## Goal

Create a portable desktop device that displays:

- Album Art
- Song Title
- Artist Name
- Lyrics
- Playback Controls
- Wi-Fi Connectivity
- OTA Updates

## Hardware

- ESP32-S3 N16R8
- Display (Coming Soon)
